# Список покупок

Простое веб-приложение для ведения списка покупок. Можно добавлять товары с ценой и категорией, отмечать купленное, удалять ненужное и видеть итоговую сумму.

https://github.com/shidest/Pet-Project-with-DOM-kt-/

## Возможности

- Добавление товара: название, цена, категория
- Отметка «куплено» (галочка, зачёркивание)
- Удаление товара
- Фильтр по категориям: Продукты / Для дома / Другое
- Автоматический подсчёт суммы к покупке
- Сохранение в localStorage — данные не пропадают после перезагрузки

## Технологии

- HTML5
- CSS3
- JavaScript (ES-модули)
- Только нативные DOM API — без библиотек и фреймворков
